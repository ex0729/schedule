# DESIGN SYSTEM

- 최종 갱신: 2026-08-05
- 브랜드 작업명: ClassLink

## 원칙

- 가장 중요한 행동 하나를 짙은 녹색으로 강조한다.
- 상태는 색상 + 아이콘/텍스트를 함께 써서 구분한다.
- 개인 일정 공개 범위와 회사 화면에서 보일 결과를 행동 가까이에 표시한다.
- 모바일은 빠른 입력/오늘 일정, 데스크톱은 비교/필터/배정 밀도를 우선한다.
- Higgsfield·Creatify·Runway의 탐색성/단계화/영역 분리를 참고하되 구성과 시각 자산은 복제하지 않는다.

## 토큰

| 범주 | 토큰 | 값/용도 |
|---|---|---|
| 브랜드 | `brand-700/600/100` | `#205b4b / #2d715f / #dff2e9` |
| 중립 | `ink-950/700/500` | 본문 계층 |
| 표면 | `mist-50`, `paper`, `line` | 배경/카드/경계 |
| 강조 | `accent-500` | 응답 필요 등 보조 강조 |
| 위험 | `danger-600` | 오류·충돌·파괴 행동 |
| 간격 | 4, 8, 12, 16, 24, 32, 48, 64 | 4px 기반 |
| 반경 | 10, 16, 24px | 입력/카드/강조 패널 |
| 그림자 | card | 깊이 1단계, 정보 표에는 최소화 |

## 상태 표현

- 출강 가능: 초록 + 체크 + “가능”.
- 응답 대기/확인 필요: 호박 + 시계/물음표 + 문구.
- 배정 완료: 짙은 청록 + 체크 원 + “배정 완료”.
- 충돌/오류: 적색 + 경고 아이콘 + 원인/복구 행동.
- 취소: 중립 회색 + 취소선 또는 X + “취소”.
- 일정 미등록: 점선 테두리 + 빈 캘린더 아이콘 + “미등록”.

## 타이포그래피와 그리드

- Noto Sans KR, fallback sans-serif. 본문 16px, 보조 12~14px, 화면 제목 28~40px.
- 글줄은 70자 안팎, 한국어는 의미 단위 줄바꿈을 우선한다.
- 데스크톱 최대 1180px/12열, 태블릿 8열, 모바일 4열.
- breakpoints: 600px, 900px, 향후 데이터 표 전용 1200px.

## 컴포넌트 규격

- 버튼: 44px 이상, primary/secondary/ghost/danger. 로딩 중 중복 제출 금지.
- 입력: 48px 기본, label 상시 노출, 오류는 필드 바로 아래에 원인과 해결법 표시.
- 선택: 라디오/체크박스 자체 의미를 유지하고 카드형 외형에서도 키보드 포커스 제공.
- 배지: 아이콘 또는 형태 + 텍스트 필수. 색만 사용 금지.
- 카드: 한 카드 한 목적. 중첩 2단계 이하.
- 표: 고정 헤더, 정렬 상태, 행 키보드 접근, 모바일에서는 카드/단계형 목록으로 변환.
- 캘린더 셀: 날짜, 일정 수, 충돌/비공개 표식. 색상만으로 종류를 구분하지 않는다.
- 모달/드로어: 확인은 모달, 모바일 상세/편집은 드로어. 포커스 트랩과 복귀 필수.
- 토스트: 작업 결과 보조 알림이며 오류의 유일한 전달 수단으로 쓰지 않는다.
- 빈/오류/권한 부족: 이유, 현재 상태, 가능한 다음 행동을 제공한다.
- 스켈레톤: 실제 레이아웃 크기를 반영하고 3초 이상이면 진행 설명을 추가한다.
- 내비게이션: 모바일 하단 최대 5개, 데스크톱 사이드바는 역할별 메뉴와 조직 문맥 표시.

## 화면별 공통 패턴

- 인증: 역할을 먼저 선택해 이후 필드와 진입 경로를 명확히 한다.
- 강사 홈: 오늘 일정 → 응답 필요 요청 → 공개 상태 순.
- 회사 대시보드: 미배정/위험 수업 → 필요/확보 인원 → 응답 현황 순.
- 등록: 핵심 필수값 먼저, 선택 정보는 접어서 점진 공개.
- 공개 설정: 설정값과 “회사에서 보이는 모습” 미리보기를 나란히 제공.

## 접근성과 모션

- WCAG 2.2 AA를 목표로 색 대비, 키보드, 이름/역할/상태, 44px 터치 영역을 검증한다.
- `prefers-reduced-motion`에서 비필수 모션을 제거한다.
- 120~220ms의 짧은 상태 전환만 사용하고 업무 완료를 지연하는 장식 모션은 금지한다.
