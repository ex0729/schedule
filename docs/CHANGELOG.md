# CHANGELOG

사용자에게 의미 있는 변화만 기록한다.

## 2026-08-05

### 수정

- Vercel이 Next.js 빌드 결과 대신 `public` 폴더를 찾던 배포 설정 오류를 수정했다.

### 추가

- 강사 또는 교육회사 담당자 역할을 선택하는 이메일 회원가입 화면.
- 이메일/비밀번호 로그인, 이메일 확인 callback, 보호된 역할별 환영 화면, 로그아웃.
- 개인정보 기본 비공개 원칙을 반영한 반응형 랜딩·인증 UI.

### 보안

- 서버 입력 검증, Supabase 쿠키 세션 갱신, 보호 화면의 서버 사용자 재검증.
- 가입 역할을 직접 수정할 수 없는 DB 프로필로 기록하고 본인 읽기 RLS 적용.
